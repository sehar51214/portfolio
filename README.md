# Sehar Batool | Developer Portfolio

A responsive personal portfolio website built as **Task 1: Personal Developer Portfolio & Project Showcase** for the Datheon internship program.

🔗 **Live Demo:** 
http://seharbatoolportfolio.netlify.app

---

## Features

- 📱 **Mobile-first responsive layout** built with Flexbox and CSS Grid
- 🌙 **Dark theme by default** with a light/dark toggle (choice is saved in the browser)
- ⌨️ **Typing animation** for the name and roles in the hero section
- 🍔 **Mobile hamburger menu** with smooth scrolling navigation
- 🪟 **Project modal popups** showing details for each project
- ✨ **Scroll reveal animations** for sections and cards
- ♿ Respects the user's reduced-motion setting

## Sections

1. **Hero:** name, role and call-to-action buttons
2. **About Me:** short professional summary
3. **Skills:** core technologies and tools
4. **Featured Projects:** project cards with detail popups
5. **Education & Achievements:** academic background and certifications
6. **Contact:** email and LinkedIn links

## Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Semantic page structure (`header`, `main`, `section`, `footer`) |
| CSS3 | Variables, Flexbox, Grid, media queries, animations |
| JavaScript (ES6+) | Theme toggle, hamburger menu, typing effect, modal, scroll reveal |
| GitHub Pages | Hosting |
